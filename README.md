# Customer Churn Prediction - MLOps Project

A complete end-to-end Machine Learning project that predicts whether a customer is likely to churn. The trained ML model is exposed through a FastAPI REST API, containerized using Docker, deployed on Render, and connected to a web-based frontend.

## 📌 Project Overview

Customer churn prediction is a machine learning problem where the goal is to identify customers who are likely to stop using a company's service.

This project demonstrates the complete ML deployment lifecycle:

```text
Customer Input
      ↓
HTML / CSS / JavaScript Frontend
      ↓
FastAPI REST API
      ↓
Trained ML Model
      ↓
Churn Prediction + Probability
      ↓
Result displayed to User
